## Notes on usage

- This file now covers all 6 Phase 1 topics in one place, including General Science Facts (previously in a standalone file `general-science-facts-subtopics.md` — this file supersedes it).
- Each topic's 50 subtopics follow the same clustering logic — grouped by natural sub-domain, most ending with a "Curiosities / Myths" cluster to keep entries engaging and shareable.
- Sensitive clusters (religious festivals, colonialism, Holocaust, apartheid, 9/11, Pride Month) are flagged for **extra editorial care** — factual, neutral, respectful tone is required per Section 5 of `site-rules.md`. These are good candidates for extra source-citation rigor.
- As with General Science Facts, recommend building a status-tracking table per topic once entries start getting drafted (see the table template in `general-science-facts-subtopics.md`).
